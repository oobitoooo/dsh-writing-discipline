# 文风指纹（baseline）

## 1. 它回答什么

**「这段还像不像我写的？」**

规则扫描回答「有没有毛病」，守恒锁回答「事实有没有被改」，指纹回答「风格是不是你的」。三件事不重叠：

| | 判什么 | 典型触发 |
|---|---|---|
| 规则 | 对错 | 「作为一个 AI」「请注意」「全网最低」 |
| 守恒锁 | 真假 | 数字被删、`可能` 变 `导致` |
| 指纹 | 像不像 | 句长翻倍、句子变整齐、口头禅消失 |

## 2. 指标（只有六个，多了没用）

| 指标 | 为什么选它 |
|---|---|
| 平均句长（汉字数） | 最稳定的个人特征。有人一句 12 字，有人 25 字，很少变 |
| 句长变异系数（CV） | 真人的句长参差，模型写的整齐。这条比平均句长更能识别「不像」 |
| 单句最多逗号数 | 你习惯一句话塞几个判断 |
| 单句最多「的」数 | 长定语链的密度 |
| 被动句密度（每千字） | 「被」用得多，通常意味着书面化、责任模糊化 |
| 口头禅（高频二元组） | 你反复用的词；它们消失是最直观的「不像」 |

**没有用到的指标**：词性分布、句法树深度、情感值、可读性公式。原因统一——那些指标在不同题材之间漂得比「人是谁」还厉害，拿来判人只会误伤。

## 3. 样本怎么选

- **同类型**：都是报告，或都是邮件。混着用等于没有基线。
- **数量**：2 份起步，5–10 份最稳。少于 2 份直接报错，不给你假基线。
- **长度**：每份中文 ≥60 字、≥4 句。太短的文件会被跳过。
- **只算自然段**：Markdown 的标题、列表、表格、代码块先剔除。否则「- 修好了」「| 项目 | 值 |」这类行会把平均句长拉到个位数。

## 4. 判定逻辑

不做加权总分，只做三档，靠偏离项的权重和：

```
score = Σ item.weight
score < 0.6        → 像你
0.6 ≤ score < 1.6  → 有点漂
score ≥ 1.6        → 不像你
```

各条的触发条件：

| 项 | 触发 | 权重 |
|---|---|---|
| 句长偏离 | 与基线中位数相差 ≥35% | 0.3–1.0（按偏离幅度） |
| 句子过于整齐 | CV < 0.45 **且** CV < 基线中位数 × 0.6 | 0.8 |
| 逗号链过长 | 超过基线 p90 再加 2 | 0.5 |
| 被动句变多 | 超过基线 p90 × 1.6 且 ≥3 次 | 0.4 |
| 口头禅缺失 | 基线 top12 里至少 2 个没出现 | 0.3 |

## 5. 已知误报

- **换题材**：用邮件建的基线去判技术文档，必然说「不像你」。这不是 bug，是基线选错了。
- **写得比平时好**：刻意写得更正式、更完整时，句长和 CV 都会偏，会被判「漂」。忽略即可。
- **翻译腔**：译稿的句长天然接近原文语言，和你的中文基线差很远。
- **样本太少**：2 份样本的基线只能说「大概」，5 份以上才稳。

## 6. 存了什么

`~/.dsh/writing-discipline/baseline.json`：

```json
{
  "version": 1,
  "createdAt": "2026-11-12T...",
  "samples": 4,
  "files": ["AGENTS.md", "README.md", "PITFALLS.md"],
  "metrics": {
    "avgSentenceZh": { "median": 13, "p10": 9, "p90": 19 },
    "sentenceLenCV": { "median": 0.67, "p10": 0.41, "p90": 0.92 },
    "commaChainMax": { "median": 2, "p10": 1, "p90": 4 },
    "deChainMax": { "median": 1, "p10": 1, "p90": 2 },
    "passivePer1000": { "median": 0.8, "p10": 0.2, "p90": 2.1 }
  },
  "petWords": [{ "w": "进程", "n": 12 }],
  "exemplar": "这些都是开发过程中真踩到、真修过的坑"
}
```

**没有原文，只有数字和一句原型句。** 原型句是为了在报告里给你看「你平时长这样」——它来自你的一篇样本，长度最接近中位数。不想要就手动删掉这个字段，报告会自动省略对照。

## 7. 前端为什么长这样

一页只有三块：一句结论、几张「哪儿不一样」的卡片、一条段带加一排句长竖条。数字折叠在最底下。

理由：指标仪表盘看起来专业，但读完不知道该改哪句。**偏离项 + 你自己的句子**才是能动手的东西。所以报告里每个结论后面都跟着对照，而不是一个 7.2 分。

### 两种模式，一个页面

| 有没有旧稿 | 页面怎么变 |
|---|---|
| 有基线 | 结论按「像不像你」给；下面先列与旧稿的差异，再列段落层面的离群 |
| 没基线 | 自动降级：只做段落一致性，结论变成「这篇前后是一个人在写 / 不太统一」，并说明这次没有尺子 |

降级是刻意设计的：**拿到一篇稿子就该能出东西**，不该因为「你还没建基线」把人挡在门外。

### 段落一致性怎么判

把稿子按空行切段（每段至少 25 个汉字），算每段的平均句长、句长整齐度、被动密度，取**中位数**当基准，标出偏离的段：

- 段平均句长 > 中位数 × 1.5
- 段句长整齐度 < 中位数 × 0.5（这段明显更「匀」）
- 段被动密度 > 中位数 × 2 且被动句 ≥2

少于 4 段时不做判定——样本太少，怎么比都像。

### 结论会跟着段落走

整篇指标落在基线范围内、但内部有两段明显离群时，标题不会说「这篇读起来就是你」。这种情况会降成「大体是你的路子，但有 2 段不像你自己的写法」。避免「标题说像、下面列了两条不像」的自相矛盾。
